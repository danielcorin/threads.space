# Security Policy

Threads is deprecated and no longer actively maintained. There are no supported
releases or guaranteed security updates. Deployment owners are responsible for
securing their instances and keeping dependencies up to date.

Please do not open public issues for vulnerabilities or leaked credentials.
Use [GitHub private vulnerability reporting](https://github.com/danielcorin/threads.space/security/advisories/new)
when it is enabled for this repository. If the form is unavailable, do not post
sensitive details publicly. A response or fix is not guaranteed. When sharing
logs or configuration, remove API tokens, Worker secrets, session IDs, and
private channel or message contents.
